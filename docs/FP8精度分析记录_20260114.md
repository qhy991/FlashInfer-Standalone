# FP8 精度分析记录

## 日期
2026-01-14

## 问题描述

在 FlashInfer vs Standalone GQA Decode 的直接数值对比中，FP8 模式出现了显著的精度差异：
- **FP16 模式**: 误差 0.017% ✓
- **FP8 模式**: 误差 57.77% ✗

## 根本原因

### 量化策略不同

| 实现 | Scale 策略 | FP8 转换方法 |
|------|-----------|-------------|
| **FlashInfer** | Per-Tensor (整个张量一个 scale) | PyTorch 内置 `.to(float8_e4m3fn)` |
| **Standalone (原始)** | Per-Head (每个 head 独立 scale) | 自定义 `float_to_fp8_e4m3_host()` |

### 详细说明

#### FlashInfer 的实现

```python
# 对比脚本中的 FlashInfer 量化
def quantize_to_fp8(tensor):
    # Per-Tensor: 使用整个张量的最大值
    scale = tensor.abs().max().item() / 448.0
    tensor_fp8 = (tensor / scale).to(torch.float8_e4m3fn)
    return tensor_fp8, scale
```

**数据流**：
```
K: [kv_len=128, num_kv_heads=8, head_dim=128]
    ↓ abs().max()
scale = 2.0 / 448 = 0.004464  # 单个值
    ↓
K_fp8 = (K / 0.004464).to(float8_e4m3fn)
```

#### Standalone 的实现（原始）

```cpp
// src/gqa_decode_sm89_standalone.cu:1892-1912

for (int head = 0; head < num_kv_heads; ++head) {
    // Per-Head: 每个 head 独立计算 scale
    float k_max = 0.0f;
    for (int kv = 0; kv < kv_len; ++kv) {
        for (int d = 0; d < head_dim; ++d) {
            k_max = fmax(k_max, fabsf(__half2float(h_k[idx])));
        }
    }
    h_k_scale[head] = k_max / 448.0f;  // 每个独立的 scale
}
```

**数据流**：
```
K: [kv_len=128, num_kv_heads=8, head_dim=128]
    ↓
for each head in 0..7:
    max_this_head = max(K[:, head, :])
    scale[head] = max_this_head / 448  # 8 个独立的 scale
    ↓
    K_fp8[:, head, :] = float_to_fp8(K[:, head, :] / scale[head])
```

### 数值差异示例

假设 KV cache 数据：
```
Head 0: 范围 [-1.0, 1.0],     max = 1.0
Head 1: 范围 [-0.5, 0.5],     max = 0.5
Head 7: 范围 [-2.0, 2.0],     max = 2.0
全局最大值: 2.0
```

**Per-Tensor (FlashInfer)**:
```
scale = 2.0 / 448 = 0.004464

Head 0: K[:, 0, :] / 0.004464 → FP8 范围 [-224, 224]
Head 7: K[:, 7, :] / 0.004464 → FP8 范围 [-448, 448]
```
→ Head 0 的精度较低

**Per-Head (Standalone 原始)**:
```
scale[0] = 1.0 / 448 = 0.002232
scale[7] = 2.0 / 448 = 0.004464

Head 0: K[:, 0, :] / 0.002232 → FP8 范围 [-448, 448]
Head 7: K[:, 7, :] / 0.004464 → FP8 范围 [-448, 448]
```
→ 所有 head 都充分利用 FP8 范围

### Softmax 放大效应

```
Attention(Q, K, V) = softmax(Q @ K^T / sqrt(d)) @ V

1. FP8 量化误差:
   FlashInfer: 部分 head 精度低
   Standalone: 所有 head 精度一致

2. Attention Score:
   scores = Q @ K^T
   不同的 K 量化 → 不同的 scores

3. Softmax (指数放大):
   softmax([x1, x2, x3]) = [exp(x1)/sum, ...]
   scores 的 ±0.01 差异 → softmax 输出 ±5-10% 差异

4. 最终输出:
   output = softmax(scores) @ V
   差异累积 → 57.77%
```

## 解决方案

### 方案选择

**选择**: 修改 Standalone 使用 Per-Tensor Scale，与 FlashInfer 保持一致

**理由**:
1. FlashInfer API 限制 (`single_decode_with_kv_cache` 只接受标量 scale)
2. 实现公平的数值对比
3. 验证 Standalone 的 kernel 实现正确性

### 实现计划

#### 1. 修改 Standalone 量化逻辑

**文件**: `src/gqa_decode_sm89_standalone.cu`

**修改前** (Per-Head):
```cpp
// 计算每个 head 的 scale
for (int head = 0; head < num_kv_heads; ++head) {
    float k_max = 0.0f;
    // ... 找每个 head 的最大值 ...
    h_k_scale[head] = k_max / 448.0f;
}
```

**修改后** (Per-Tensor):
```cpp
// 计算全局 scale
float k_max = 0.0f;
for (size_t i = 0; i < kv_size; ++i) {
    k_max = fmax(k_max, fabsf(__half2float(h_k[i])));
}
float global_k_scale = k_max / 448.0f;

// 所有 head 使用相同的 scale
for (int head = 0; head < num_kv_heads; ++head) {
    h_k_scale[head] = global_k_scale;
}
```

#### 2. 更新 compare 模式

确保 compare 模式也使用 Per-Tensor Scale。

## 验证目标

修改后，FlashInfer vs Standalone 的 FP8 直接对比误差应降低到 **< 5%**。
